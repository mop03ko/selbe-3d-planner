# Сэлбэ · 3D орон зайн студи

4–6 хүний гэр бүлийн сууцын хоёр давхрын бүх өрөө, тавилга, өнгө материалыг турших статик 3D веб.

**[Вебийг нээх](https://mop03ko.github.io/selbe-3d-planner/)**

## Боломжууд

- Хоёр давхар, 15 өрөө болон туслах хэсэг, 61 тавилгатай 2026/01 шинэ хувилбар.
- 3D, дээрээс, өрөөний доторх харагдац; нам/бүтэн хана.
- Тавилга чирж зөөх, 5 см алхам, эргүүлэх, хэмжээ ба өнгө өөрчлөх.
- 22 төрлийн тавилга нэмэх, хувилах, устгах, байрлал түгжих.
- Хэвтээ хүрээний давхцал, өрөөний хил болон хаалганы ойролцоох зайг анхааруулах.
- 4 интерьерийн хэв маяг, өрөө тус бүрийн ханын өнгө, 7 шалны материал (ёлочка паркет нэмсэн).
- ANO Design-ийн 40 эх дүрслэл, өмнөх 15 AI концепц: өрөө ба давхраар шүүх, харах өнцөг солих, зураг татах галерей.
- Буцаах/дахин хийх; тухайн төхөөрөмжийн хөтөчид автоматаар хадгалах.
- JSON хувилбар татах/оруулах, одоогийн харагдацыг PNG зураг болгох.
- Компьютер, гар утасны удирдлага.
- WebMCP дэмждэг хөтөчид төлөвлөлт унших, өрөөнд төвлөрөх локал үйлдлүүд.

## Хэрэглэх

Өрөөгөө сонгоод тавилга дээр дарж чирнэ. Хоосон хэсгийг чирж эргүүлнэ. Хулганын дугуйгаар ойртуулж, баруун товчоор дүрсийг шилжүүлнэ. Гар утсанд доод цэсээр өрөө болон тохиргоо руу орно.

`R`: 90° эргүүлэх · `Delete`: устгах · `Ctrl+Z`: буцаах · `Ctrl+Shift+Z`: дахин хийх.

**[Өрөөний рендерүүд](https://mop03ko.github.io/selbe-3d-planner/renders.html)**-ээс хоёр давхрын интерьерийг үзнэ. 3D студид өрөө сонгоод «Энэ өрөөний рендер» холбоосоор тухайн зурагт шууд орж болно. Галерейд сумтай товч эсвэл гарын `←` / `→` товчоор зургуудыг сольж, `Esc`-ээр хаана.

## Хөгжүүлэлт

Node.js 22.12+ (эсвэл 24 LTS), npm шаардлагатай.

```sh
npm ci
npm run dev
npm test
npm run build
```

Vite нь статик үр дүнг `docs/` хавтаст гаргана. `base: './'` нь GitHub Pages-ийн төслийн замаас зөв ачаалахад зориулагдсан. Хамаарлууд lockfile-д түгжигдсэн.

GitHub Pages-ийн source: `main` branch, `/docs` folder. Засварын дараа `npm run build` ажиллуулж, эх код болон `docs/`-ийг хамт commit/push хийнэ. `node_modules`-ийг нийтлэхгүй.

## Эх сурвалж ба хязгаар

2026-09-30-нд хэрэглэгчийн өгсөн шинэ эх сурвалжаар шинэчлэв:

- **Selhe 2 house interior, ajliin zurag.pdf**, ANO Design, 2026/01: PDF хуудас 4, 24 дэх тавилгын байгуулалт; өнгөлгөө, таазны хуудсууд.
- **1floor ajlin zurag.pdf**, 2025/12: өмнөх нэгдүгээр давхрын зураг. Зөрүүтэй хэсэгт шинэ 2026/01 зургийг үндэслэв.
- **SELEH inteiror.pdf**: PDF хуудас 2–41 дэх 40 интерьер дүрслэл. ANO Design-ийн зохиогчийн тэмдэглэгээг хадгалж, бүтэн хуудсыг JPG болгон галерейд оруулав. Шинээр AI-аар бүтээсэн зураг биш.

Шинэ PDF файлуудыг бүхлээр нь нийтлээгүй. Галерейн эх JPG хуудсууд `public/references/ano-2026/` дотор байна.

Дотор талбайн хүснэгтийн нийлбэр 180.96 м². Террас 57.92 м², тагт 10.60 м²; эдгээрийг эх зурагт 30%-иар жигнэсэн. Өрөөний полигон болон нээлхийн дүрслэл схемчилсэн тул дүрснээс хэмжээс авахгүй. Тавилга болон 3D геометр процедурын аргаар дүрслэгдсэн концепц; үйлдвэрлэлийн/CAD/BIM зураг биш.

Ханын бүтэц, шат, хаалга, цонх тогтмол. Түгжээ тайлсан усны цэг, гал тогоог туршилтаар зөөж болно; инженерийн шугам болон төхөөрөмжийн угсралтын шаардлагыг баталгаажуулахгүй. Давхцлын шалгалт нь бүрэн хаалганы нээлт, гарц, явах замын өргөн, барилгын нормын шалгалт биш.

Хувилбар зөвхөн тухайн хөтөчийн localStorage-д хадгалагдана. Сервер рүү хэрэглэгчийн хувилбарыг илгээхгүй. Өөр төхөөрөмжид ашиглахад JSON export/import хийнэ. GitHub Pages нь нийтэд нээлттэй эхний загварыг байршуулна.

Гал тогооны санааны 3 зургийг өмнөх интерьерийн ажлаар Imagegen-ээр бүтээсэн. UI-ийн үндсэн фонт нь Manrope, боломжгүй үед системийн фонт ашиглана.

«Өмнөх AI концепц» хэсгийн 15 рендерийг эхний төлөвлөлтийн өнгө, материалын санаанд тулгуурлан AI-аар бүтээсэн. Шинэ цуглуулгад 10 өрөө, хэсгийн 40 эх дүрслэл бий. Шинэ PDF-д тусдаа рендергүй техникийн өрөө, террас, дээд хонгил, дээд шат, тагтад өмнөх AI концепцийг ил тод шошголсон. Рендерүүд нь тусдаа концепц зураг; 3D студид хэрэглэгчийн хийсэн тавилгын өөрчлөлттэй автоматаар синхрончлохгүй, CAD зураг биш. Өрөөний нэр, талбайг `src/data.js`-ээс `public/renders/rooms.json` руу авсан. Галерей `public/renders.html`, зураг болон дагалдах файлууд `public/renders/` дотор байна.

## 2026/01 интерьерийн өөрчлөлт

Улбар шар дээд шүүгээ, ханын хамгаалалттай крем гал тогоо; 2 × 1 м ширээ, 8 суудал. Зочны өрөөнд дөрвөн сандал, 2.203 × 0.871 м буйдан, дөрвөлжин кофе ширээ. Гурван өрөөнд 1.65 × 2 м хоёр хүний ор, жижиг өрөөнд нэг хүний ор. Мастер өрөөнд шүүгээний хэсэг, ор, тусдаа амралтын хэсэг, чулуун шал. Үүдний улбар шар суудал, ёлочка паркет, бүтэн ханын горимд модон таазны хөндлөвч, хар цонхны хүрээ нэмсэн. Тагтны L хэлбэрийг шинэ байгуулалтад ойртуулсан.

Хадгалалт: шинэ загвар `selbe-layout-2026-01`, өмнөх загвар `selbe-layout-v1` гэсэн тусдаа түлхүүртэй. Хуучин түлхүүрийг өөрчлөхгүй. «2026 ажлын зураг» товчоор шинэ анхны загвар болон тухайн хөтөчид хадгалсан өмнөх хувилбарыг нээнэ; сольсон үйлдлийг undo-оор буцаана. Хуучин JSON импорт хүчинтэй хэвээр. Өрөөний ID өөрчлөгдөөгүй.

3D геометр нь эх зурагт ойртуулсан схем: гоёлын детал, гэрэлтүүлэг, тавилгын хийц нь дизайнерийн эх рендертэй яг адил биш. Галерейн зургууд 3D засвартай автоматаар өөрчлөгдөхгүй.
