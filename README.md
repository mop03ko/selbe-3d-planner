# Сэлбэ · 3D орон зайн студи

4–6 хүний гэр бүлийн сууцын хоёр давхрын бүх өрөө, тавилга, өнгө материалыг турших статик 3D веб.

**[Вебийг нээх](https://mop03ko.github.io/selbe-3d-planner/)**

## Боломжууд

- Хоёр давхар, 15 өрөө болон туслах хэсэг, 52 тавилгатай эхний хувилбар.
- 3D, дээрээс, өрөөний доторх харагдац; нам/бүтэн хана.
- Тавилга чирж зөөх, 5 см алхам, эргүүлэх, хэмжээ ба өнгө өөрчлөх.
- 21 төрлийн тавилга нэмэх, хувилах, устгах, байрлал түгжих.
- Хэвтээ хүрээний давхцал, өрөөний хил болон хаалганы ойролцоох зайг анхааруулах.
- 3 интерьерийн хэв маяг, өрөө тус бүрийн ханын өнгө, 5 шалны материал.
- Буцаах/дахин хийх; тухайн төхөөрөмжийн хөтөчид автоматаар хадгалах.
- JSON хувилбар татах/оруулах, одоогийн харагдацыг PNG зураг болгох.
- Компьютер, гар утасны удирдлага.
- WebMCP дэмждэг хөтөчид төлөвлөлт унших, өрөөнд төвлөрөх локал үйлдлүүд.

## Хэрэглэх

Өрөөгөө сонгоод тавилга дээр дарж чирнэ. Хоосон хэсгийг чирж эргүүлнэ. Хулганын дугуйгаар ойртуулж, баруун товчоор дүрсийг шилжүүлнэ. Гар утсанд доод цэсээр өрөө болон тохиргоо руу орно.

`R`: 90° эргүүлэх · `Delete`: устгах · `Ctrl+Z`: буцаах · `Ctrl+Shift+Z`: дахин хийх.

## Хөгжүүлэлт

Node.js 22.12+ (эсвэл 24 LTS), npm шаардлагатай.

```sh
npm ci
npm run dev
npm test
npm run build
```

Vite нь статик үр дүнг `docs/` хавтаст гаргана. `base: './'` нь GitHub Pages-ийн төслийн замаас зөв ачаалахад зориулагдсан. Хамаарлууд lockfile-д түгжигдсэн.

GitHub Pages-ийн source: `main` branch, `/docs` folder. Засварын дараа `npm run build` ажиллуулж, эх код болон `docs/`-ийг хамт commit/push хийнэ. `node_modules`-ийг нийтлэхгүй.

## Эх сурвалж ба хязгаар

Хэрэглэгчийн өгсөн **Selbe ajliin zurag.pdf**, БА-3/БА-4 байгуулалт болон урьдчилсан тавилгын төлөвлөлтөд үндэслэв. Эх PDF-ийг энэ санд нийтлээгүй.

Дотор талбайн хүснэгтийн нийлбэр 180.96 м². Террас 57.92 м², тагт 10.60 м²; эдгээрийг эх зурагт 30%-иар жигнэсэн. Өрөөний полигон болон нээлхийн дүрслэл схемчилсэн тул дүрснээс хэмжээс авахгүй. Тавилга болон 3D геометр процедурын аргаар дүрслэгдсэн концепц; үйлдвэрлэлийн/CAD/BIM зураг биш.

Ханын бүтэц, шат, хаалга, цонх тогтмол. Түгжээ тайлсан усны цэг, гал тогоог туршилтаар зөөж болно; инженерийн шугам болон төхөөрөмжийн угсралтын шаардлагыг баталгаажуулахгүй. Давхцлын шалгалт нь бүрэн хаалганы нээлт, гарц, явах замын өргөн, барилгын нормын шалгалт биш.

Хувилбар зөвхөн тухайн хөтөчийн localStorage-д хадгалагдана. Сервер рүү хэрэглэгчийн хувилбарыг илгээхгүй. Өөр төхөөрөмжид ашиглахад JSON export/import хийнэ. GitHub Pages нь нийтэд нээлттэй эхний загварыг байршуулна.

Гал тогооны санааны 3 зургийг өмнөх интерьерийн ажлаар Imagegen-ээр бүтээсэн. UI-ийн үндсэн фонт нь Manrope, боломжгүй үед системийн фонт ашиглана.
